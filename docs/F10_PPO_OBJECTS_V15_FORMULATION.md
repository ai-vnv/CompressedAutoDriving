# F10-PPO V15 — Retention-Preserving C2 Distillation

V14 provided a safe pedestrian checkpoint but failed the frozen C1 retention
gate: C1 completion fell from 1.0 to 0.0. The failure occurred already at PPO
step zero, after behavior warm-start, because every imitation target came from
the pedestrian-aware simple controller. Later canonical PPO updates did not
recover the lost driving skill.

V15 changes only C2 actor initialization. It keeps the canonical PPO algorithm,
reward, 29-dimensional observation, action adapter, MobileNet lane measurement,
lane EKF, frozen YOLO/F9c pedestrian path, scenarios, and acceptance thresholds.

## Runtime perception

- C0/C1: front RGB -> frozen MobileNet lane measurement -> lane EKF -> PPO.
- C2: the same lane path plus front RGB -> frozen YOLO `duckie` detection ->
  calibrated metric measurement -> frozen F9c pedestrian belief -> PPO.
- C3: the same lane path plus front RGB -> frozen YOLO `stop_sign` detection ->
  stop belief/state -> PPO.

Neither actor nor critic receives privileged truth.

Catastrophic-forgetting retention uses matched trajectories. The imported C1
checkpoint and each C2 candidate run on the same frozen V15 C1 development
seeds. The pre-registered maximum completion-rate drop of 0.25 is applied to
that paired baseline; the gate does not assume that an imported checkpoint
completes every newly sampled trajectory.

## Pre-registered C2 initialization change

The immutable distillation snapshot contains equal row counts from training-only
policy telemetry:

1. C1 no-pedestrian observations. Targets are deterministic actions from the
   selected V9 C1 checkpoint itself, preserving its driving function.
2. C2 pedestrian observations. Targets are generated by the belief-aware simple
   controller using only the same normalized 29D public policy vector.

The two sources have equal total loss weight. This prevents the safety-weighted
pedestrian stop rows from numerically overwhelming C1 retention examples. The
snapshot contains only `policy.*` values and an offline source-role label; it
contains no `evaluation_gt.*` fields. Runtime C2/C3 remains real RGB/YOLO/belief.

V14 is retained as a failed attempt. V15 uses new disjoint seeds. C2 development,
C1 retention, and stage-final thresholds are unchanged. C3 remains forbidden
until C2 is classified PASS. Stop after C3; C4 is out of scope.
